# Brand assets

The editable source files are:

- `macos-data-rescue-icon.svg` — square project icon and favicon master.
- `og-image.svg` — Open Graph / social preview master at a `1200 × 630` view box.

Generated delivery files:

- `icon-512.png` — high-resolution square icon.
- `apple-touch-icon.png` — 180 × 180 Apple touch icon.
- `favicon-16x16.png`, `favicon-32x32.png`, and `favicon-48x48.png` — browser favicon sizes.
- `favicon.ico` — multi-size ICO containing 16, 32, 48, and 256 pixel variants.
- `og-image.png` — 1200 × 630 Open Graph image.

Core palette: navy `#0b1730`, rescue green `#27cda5`, mint `#8fe3d0`, and signal yellow `#ffc84a`.
